## Key evidence and distractors

### `A1:reading:batch071-plant-ogen:1`

- **q1, A: Haar beker.** Evidence: “Neem je beker mee.” The salutation identifies Lina as the recipient. B selects milk already on the table. C selects sugar already by the window. All options are two-word object phrases. The question asks what Lina must bring, rather than what is present.
- **q2, B: In de keuken.** Evidence: “De koffie staat in de keuken.” A substitutes the milk's location. C substitutes the sugar's location. Every option is a three-word location phrase.

### `A1:reading:batch071-hoed-les:1`

- **q1, C: Voor Noor.** Evidence: “We maken een kaart voor Noor.” A selects Sara, the teacher who writes the message. B selects Sami, the learner who receives it. Both appear explicitly, but the card's recipient is Noor. All options have the same preposition plus one name.
- **q2, A: Drie.** Evidence: “Neem drie potloden mee.” B reuses the number of books. C reuses the number of pens. All choices are one written number. There is no calculation.

### `A1:reading:batch071-winkel-sok:1`

- **q1, B: Op vrijdag.** Evidence: “U kunt de jas vrijdag halen.” A selects the day the shop is closed. C selects the day it closes early. The text states the collection day explicitly. All choices use “Op” plus one day.
- **q2, C: Twaalf euro.** Evidence: “U betaalt twaalf euro.” The sentence follows the coat collection instruction. A selects the sock's price. B selects the bag's price. All options use a written number plus “euro”; no addition or comparison is required.

### `A1:reading:batch071-eend-tas:1`

- **q1, A: Met de trein.** Evidence: “Ik kom met de trein.” Roos signs the message. B selects her bicycle, which is at home. C selects Noor's transport. All choices have the same three-word structure.
- **q2, B: Noor.** Evidence: “Noor komt met de bus.” A selects Karim, the message's recipient. C selects Roos, who explicitly comes by train. All choices are one name. No item asks who owns the duck or where a bag is located.

### `A1:reading:batch071-beer-dokter:1`

- **q1, C: In kamer twee.** Evidence: “U wacht in kamer twee.” A selects the doctor's room. B selects the room with the bed. All options use the same structure with one different number.
- **q2, A: Koffie.** Evidence: “De dokter drinkt koffie.” B selects the patient's drink. C selects the drink by the stuffed bear. All choices are familiar one-word drinks. No question requires medical knowledge.

### `A1:reading:batch071-taart-staart:1`

- **q1, B: Op zaterdag.** Evidence: “We eten zaterdag bij mij.” A selects Ivo's bread-shopping day. C selects his visit to his sister. The salutation and question identify Mila as the invited friend. All choices use “Op” plus one day.
- **q2, C: Een bord.** Evidence: “Neem een bord mee.” A and B select items Ivo already has: glasses and spoons. All options use “Een” plus one object. No answer depends on recognising the cake's shape.

### `A1:reading:batch071-kat-werkt:1`

- **q1, A: Thuis.** Evidence: “Ik werk thuis.” Nora signs the message. B selects Amir's workplace. C selects Sara's workplace. The key is the shortest option, rather than carrying extra specificity.
- **q2, B: Om vier uur.** Evidence: “Bel me om vier uur.” A selects Nora's eating time. C selects her finishing time. All options have the same three-word structure. The question asks for the printed call time without a calculation.

### `A1:reading:batch071-koffer-les:1`

- **q1, C: Haar jas.** Evidence: “Neem je jas mee.” A selects the book that stays at home. B selects the pen the teacher supplies. All choices are two-word object phrases.
- **q2, A: In de auto.** Evidence: “De tassen staan in de auto.” B selects where the learners sit. C selects where the teacher sits. These distinct locations avoid a bag being both beside a tree and on the grass. All choices are three-word location phrases.

## Language control

Counts use whitespace-delimited words, including greetings and sign-offs. The checker-style sentence split uses punctuation followed by whitespace; an unpunctuated salutation or sign-off can attach to a sentence. These figures therefore overstate some main-sentence lengths.

All complete messages have 25–60 words. Main clauses use the present tense. There are no subordinate clauses, idioms needed for an answer, combined conditions, calculations or negative questions. The closed park and closed shop anchor distractors but are not the tested negative fact. The cat “works” as a light visual joke, and understanding that joke is unnecessary for either answer.

The small challenge comes from matching one fact to the right object, name, day, room or quantity. A learner can reread the short message. Several texts have three nearby alternatives, as required by the A1 reading blueprint; this is not the lower-memory-load listening format.
