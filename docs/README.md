# Documentation

- `development.md` — the developer guide: configuration, commands, layout, how the app works, operations.
- `briefs/` — the author and review briefs the content sub-agents follow (`content/blueprint.md` §12).
- `screenshots/` — the pictures the README shows.
- `research/` — dated working notes: feasibility, service plan, design directions, feedback evaluations, infrastructure. They record decisions at the time they were written; the code and `DESIGN.md` are authoritative where they differ.
- `pilots/` — the first original A2 and B1 reading pilots that seeded the catalogue.
- `design-archive/` — the earlier self-contained design prototypes.
