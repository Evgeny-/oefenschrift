# Author brief

You write one content batch for the inburgering practice app. The coordinator's task names the batch id, the exam part, the task types and counts, the domains and the subjects to avoid; everything else is here and in `content/blueprint.md`.

Read first: `content/blueprint.md` (§1, §3, the §4.x section for your part, §5, §6 for audio scripts, §7 for image briefs, §8 names, §9 topics and the avoid list, §10 level control, §13); the paragraph for your part in `docs/research/exam-blueprints-2026-09-10.md` (the verified description of the official exam); `content/reviews/rubric.md`; one integrated batch of the same part as a format example (`content/batches/`); the titles of the same part in `content/catalogue.json`; `scripts/batch-check.ts` when a rule is unclear.

Write:
- `content/batches/<NNN>-original.json` — an array of items in the record shape of §3 and §4.x, ids `LEVEL:part:batch<NNN>-<slug>:1`, `status: "draft"`, `targetLevelValidated: false`. Closed items: every `evidence` a verbatim substring of `text` (listening: of the question's own fragment); keys balanced across the batch, no key three times in a row, no key that is the longest or most specific option; distractors anchored in the text and clearly false. Open tasks: `criteria` as bilingual pairs that name checkable information, a `sample` learner answer that misses exactly one criterion (`quotes` verbatim, one `null`) with one or two typical learner errors, a `model` that meets every criterion at the target level, no prompt sentence copied into sample or model. Listening: scripts with `speaker`/`role`/`text`, roles from `config/voices.json`, numbers and times in words, no fillers; `text` built mechanically from the scripts. Pictures: English `brief` with cast traits copied verbatim from `config/illustration.json`, "No text", Dutch `alt`.
- `content/batches/<NNN>-starters.json` for open tasks — keyed by id, one partial sentence per criterion, in order, each containing "…".
- `content/batches/<NNN>-notes.md` — sources and facts mirrored, per-question key rationale and what each distractor tests, language-control figures per text, a diversity matrix against the catalogue, doubts for the reviewer, the checker output.

Rules that catch authors out: fictional but plausible settings; no real organisations, brands, addresses or people — search the web for every invented company, shop or institution name before using it (two invented names in one batch turned out to be real firms); no political or religious opinion, no graphic illness or crime; neighbourhood and volunteering are over-represented, work, education, shops, health, transport and instanties are needed; a slug may not repeat a catalogue slug of the same part.

Run `npm run batch:check content/batches/<NNN>-original.json` until it reports no failures; copy the output into the notes. Do not edit the catalogue, practice sets, hints, config or app code; do not create media. Report in a few lines: the items (id, type, domain, key figures), the key distribution, doubts.
